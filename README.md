# City Route Map

A map prototype that visualizes road journeys between cities in central Sweden. It selects city pairs and animates a marker along stored road routes, making the route and movement clear and easy to follow.

## Built with

- JavaScript and HTML/CSS
- MapLibre GL JS for the map and GeoJSON layers
- Turf.js for route distance and position calculations
- OpenStreetMap road data for the route geometry
- OpenFreeMap tiles for the basemap
- React and Create React App project tooling

## Skills demonstrated

- Geospatial data handling
- Map-layer visualization
- Route animation
- Working with external map services
- Organizing large data sets into relative data sets
